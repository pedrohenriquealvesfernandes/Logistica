<h1 align="center"> People Analytics </h1>

Projeto desenvolvido com base no curso Análises Avançadas no Power BI (Prime Cursos Brasil)


## 📚 Sobre o projeto

* Projeto de análise de dados desenvolvido em Power BI, envolvendo ETL e tratamento de dados com Power Query, modelagem com tabelas fato e dimensão, relacionamentos e criação de tabela calendário. Desenvolvimento de medidas e análises em DAX, utilizando funções como CALCULATE, DIVIDE, FILTER, SWITCH e medidas dinâmicas.

* Criação de dashboards interativos com gráficos de barras, colunas, rosca, mapas, cartões, indicadores e aplicando formatação condicional, títulos e textos dinâmicos. Implementação de recursos de navegação, menus retráteis, botões, animações e interatividade.
